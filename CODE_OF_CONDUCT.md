# Code of Conduct

## Our pledge

We want this to be a project where someone who has never opened a pull request
can report that a troubleshooting step is wrong, and be thanked for it. That
requires a low-friction, unhostile space, and we commit to maintaining one
regardless of anyone's experience level, background, identity, or first
language.

## Standards

Things that make this project work:

* Assuming the other person is trying to help.
* Giving specific, actionable feedback on the content, not the contributor.
* Treating "this step is wrong" as a gift rather than an attack. A knowledge
  base where one record in five is wrong is worse than none at all.
* Writing plainly. Many contributors are working in a second language, and
  both Turkish and English are first-class in this repository.

Things that do not:

* Personal attacks, harassment, or demeaning comments.
* Dismissing a report because the reporter "should have known better".
* Publishing anyone's private information.
* Sustained disruption of discussions.

## Scope

This applies in issues, pull requests, discussions, and anywhere someone is
representing the project.

## Enforcement

Report unacceptable behaviour through GitHub's private reporting, or by
opening a private security advisory if you would rather not use a public
channel. Reports are handled confidentially.

Maintainers will respond proportionately — a clarifying comment, an edit, a
warning, or a block — depending on severity and repetition. Maintainers who do
not follow this code are subject to it like anyone else.
